# Architecture

This document owns the system's components, the communication paths between
them, the API and channel contracts, the data and sync formats, and the auth
model. It describes what *is*; why it is that way lives in `docs/adr/`, and
the rules it must keep to live in `docs/ARCHITECTURE_PRINCIPLES.md`.

## Components

*(One subsection per deployable unit: what it owns, what it must never own,
what it depends on, what depends on it.)*

Outloud is written in Swift with SwiftUI, for iOS and macOS, with one
shared Swift package and one platform module per platform (ADR 0002),
for iOS 27 and macOS 27 and later (ADR 0012). Each lives in a unit of its
own — `OutloudKit/`, `apps/macos/`, `apps/ios/` — and the apps' Xcode
projects are generated by XcodeGen (ADR 0011).

### Shared Swift package

Owns the connection to transcription, the cleanup, the settings and the
error handling. Both platform modules depend on it.

### iOS platform module

Owns recording, the shortcut integration and the clipboard (ADR 0003).
The shortcut reaches Outloud through an App Intent that Outloud exposes
to the Shortcuts app.

### macOS platform module

Owns the push-to-talk hotkey, the menu bar app and auto-paste (ADR 0004).
It is distributed as a download from GitHub and runs outside the App
Sandbox (ADR 0009).

### Models

Transcription and cleanup run on the device, on iOS and macOS, with
downloaded open models (ADR 0005). The catalogue — models, runtimes,
download sources — starts from ghost-pepper's (`plans/done/CONCEPT.md`
§"Prior art"); the first version holds Parakeet v3 and a Qwen model of
about 0.8B parameters (ADR 0006).

As in ghost-pepper, Parakeet v3 runs with FluidAudio (CoreML conversion
`FluidInference/parakeet-tdt-0.6b-v3-coreml`; iOS 17 and macOS 14 and
later), and the cleanup model is ghost-pepper's Qwen 3.5 0.8B Q4_K_M GGUF
at its pinned revision, run with LLM.swift (iOS 16 and macOS 13 and
later).

On macOS, downloaded models are stored in the Hugging Face hub cache, in
the hub's own layout, where other tools reuse them (ADR 0010); on iOS,
in the app's own container (ADR 0009).

### Microphone

Both apps record only on a user action — the trigger (ADR 0003,
ADR 0004).

### Auto-paste into other apps (macOS)

The macOS app inserts text into the focused field of another app, with
the Accessibility access the user granted. Without it, the result stays
on the clipboard (ADR 0004).

### Model downloads

Model files come from outside and are loaded into the model runtimes. On
macOS they lie in a directory shared with other apps, which every process
of the user can write to. How a model file is verified — after the
download and before it is loaded — is open.

## Data

A recording is not stored permanently by default (`docs/SPEC.md`
§"Transparency and privacy").

The history keeps, per result, the uncleaned transcript, the audio of the
recording and the cleaned version, on the device, for the period the
user sets (`docs/SPEC.md` §"History"). Voice recordings and the texts
dictated are personal data.
